# ExamMate｜國中會考五科自主學習平台

這是一個給即將參加國中教育會考學生使用的自主學習網站。個人資料、學習進度、計畫、錯題與圖片仍只儲存在目前瀏覽器的 `localStorage`；只有學生主動提交的拍照題會送到 Cloudflare Worker，再由 Google Gemini 進行辨識與分析。Gemini API Key 僅存放在 Cloudflare Secret，不會出現在前端或 GitHub。

## 網站架構

1. **初次設定**：學生建立基本資料，完成後才進入首頁。
2. **個人首頁**：依序顯示歡迎語、會考倒數、最近考試、考試時間軸、本週與本月剩餘時間、今日小目標、勉勵句與管理按鈕。
3. **日期管理**：學生可以新增、修改、刪除自訂日期；過期日期保留並標示「已結束」。
4. **五科學習**：國文、英文、數學、自然、社會共用相同的科目首頁、單元列表與練習流程。
5. **今日任務**：國文、英文、數學、自然、社會各有一個約 10 分鐘的任務，完成後更新「今日完成幾科」。
6. **錯題複習**：答錯時自動加入錯題，之後可再次作答或標記為已掌握。
7. **單元練習**：從單元列表直接開始作答；單元講義資料暫不對學生呈現，避免打斷「練習 → 找錯因 → 再練」的節奏。
8. **五科題庫**：目前共 31 個單元、326 題原創題；國文有 107 題，英文有 107 題。
9. **會考素養題**：題型含生活語境、雙文本、表格、長條圖、流程、時間軸、跨資料判讀與論證評估。
10. **108～114 會考實戰**：五科各有民國 108～114 年命題趨勢題，每次隨機抽取 10 題；題幹與解析為原創，不直接重製官方試卷。
11. **英文四大核心**：文法、短文閱讀、長文閱讀、聽力各 25 題；聽力可直接播放英文語音，也可在需要時展開逐字稿。
12. **本機資料層**：個人資料、自訂日期、每日目標、任務進度與錯題使用不同的 localStorage 索引。
13. **複習計畫系統**：學生可建立每週固定作息與讀書內容、拖曳調整日期、修改或刪除時段，並在首頁勾選今日完成進度。
14. **明亮陪讀主題**：以清透白、柔藍、水綠與杏橘營造明亮但不刺眼的陪讀感，並保留清楚對比。
15. **ExamMate 建議排程**：可依每日讀書時間與待加強科目套用「小步陪讀、五科平衡、考前整合」三種節奏，固定作息會保留，讀書卡片仍可自由修改。
16. **橫式列印週計畫**：可將本週日期、時段、複習內容、會考提醒與自我勉勵句整理成 A4 橫式表格列印。
17. **錯題整合中心**：題庫自動錯題、已存數位錯題與紙本拍照題目統一從同一頁開始；學生可先分析，再決定是否收藏與安排後續練習。
18. **弱點分析**：依未掌握題數、到期複習與錯誤原因排序科目及單元，提供下一步加強建議；已掌握題目會保留為學習紀錄。
19. **週六下週規劃提醒**：每週六 20:00 後回到首頁會自動提醒安排下週進度，可立即前往下週計畫、延後兩小時或本週略過。
20. **雙版本外觀**：可在目前的「清爽版」與粉紫、蜜桃、薄荷、晴空藍組成的「繽紛馬卡龍版」之間切換，選擇會保留在瀏覽器。
21. **完整備份與還原**：學生或家長可下載包含個人資料、計畫、進度、錯題與數位錯題圖片的 JSON 備份檔，並在另一台裝置匯入還原。
22. **雙老師錯題分析**：AI 科目老師先完成命題分析、錯因定位、解題教學與陷阱提醒；AI 筆記老師再整理知識、會考重點、比較表、口訣、時間軸與常考內容，並保留固定九段格式。
23. **紙本試題轉會考筆記**：學生可從手機拍照或電腦選圖上傳紙本題；分析完成後可列印該題的完整解析與會考重點筆記，數位錯題採開放式理解檢查，不會硬套成四選一。
24. **安全照片辨識**：題庫與數位錯題不需要 API；照片辨識透過 Cloudflare Worker 呼叫 Gemini 3.5 Flash，限制允許來源、圖片大小及每個來源 IP 每分鐘最多 10 次，禁止把 API Key 放在前端。
25. **AI 數位錯題閉環**：學生可先拍照分析，完成考點、錯因與重點整理後，再自行決定是否收藏，未收藏的照片不會自動堆進錯題本。
26. **五科 AI 加強題本**：完成 AI 錯題分析後，拍照題可直接收藏三題同觀念原創題；題庫錯題與數位錯題則在學生明確點擊後，由安全 AI 後端設計不同情境的新題，個人化題目也會納入備份。

## 檔案用途

- `index.html`：網站內容、首頁、五科、練習、錯題與對話框結構。
- `style.css`：ExamMate Design System、首頁版面、五科元件與響應式規則。
- `config.js`：唯一的預設會考、一模、二模、三模、四模日期設定區，全部使用民國年。
- `script.js`：學生資料、倒數、日期與首頁互動。
- `learning.js`：五科內容資料、今日任務、練習、立即解析、錯題、AI 加強題本與完成紀錄。
- `study-plan.js`：複習計畫、建議排程、週間作息、拖曳調整、橫式列印、今日完成狀態與 localStorage 資料。
- `digital-wrong-notebook.js`：數位錯題記錄、AI 分析後選擇收藏、圖片縮小、分類篩選、間隔複習、弱點分析與 localStorage 資料。
- `weekly-plan-reminder.js`：週六晚間提醒、延後／略過狀態、下週日期與複習計畫導引。
- `appearance-backup.js`：清爽／繽紛版切換、完整資料匯出、備份檔驗證、覆蓋前確認與安全還原。
- `ai-coach.js`：錯題整合中心、雙 AI 老師分工、紙本拍照分析、安全後端呼叫、五步驟引導、可列印會考筆記、選擇收藏、相似題建立、固定九段診斷與 localStorage 陪練紀錄。
- `question-bank.js`：五科單元重點、能力標記、難度與原創題庫的集中設定檔。
- `exam-question-bank.js`：五科中高難度會考素養題，集中管理圖表資料與詳細解析。
- `historical-exam-bank.js`：民國 108～114 年命題趨勢的五科原創實戰題與年度標記；官方原題入口集中在檔案最上方。
- `chinese-expansion-bank.js`：國文十單元擴充題庫，每單元新增 6 題。
- `english-expansion-bank.js`：英文四大核心單元與擴充題庫，含可播放的聽力內容。
- `english-question-bank-100.js`：英文第二階段擴充題，讓四個單元各達 25 題，並集中指定聽力音檔。
- `assets/audio/english/`：25 題英文聽力的本機音檔，開啟本機網站或 GitHub Pages 都可播放。
- `scripts/generate-english-audio.ps1`：需要更換聽力內容時，重新產生音檔的工具。
- `unit-review-bank.js`：保留五科單元整理資料，供未來重新開啟講義功能；目前學生頁面不呈現。
- `chinese-handbook.js`：國文十單元的完整講義、比較表、例題拆解與記憶提示。
- `english-handbook.js`：英文文法、短文、長文、聽力的完整講義與解題策略。
- `design-system.html`：配色、字體、圖示與所有共用元件的可視化規範頁。
- `content/five-subject-capability-map.md`：依會考官方方向整理的五科能力地圖。
- `content/chinese-question-bank-v1.md`：國文十單元、30 題原創題庫與完整解析。
- `README.md`：使用、測試、部署與後續擴充說明。

## Design System

在瀏覽器開啟 `design-system.html`，可以查看目前的共用規範：

- Color System、Typography、Icon Style
- Card、Button、Progress Bar
- Task Card、Practice Card、Wrong Question Card
- Dialog、Navigation、Bottom Navigation

五科頁面不各自建立新元件。科目只透過資料與辨識色改變，操作位置、文字層級及回饋方式保持一致。

## 題庫原則

題型參考國中教育會考官方命題原則所重視的生活情境、資料判讀、跨概念整合與推論方式，但所有題幹、情境、數字、選項與解析皆重新設計，不直接複製或僅換字改寫歷屆試題。基礎題集中在 `question-bank.js`，會考素養題集中在 `exam-question-bank.js`，方便後續逐科增加。

學生可以使用四種練習方式：每天固定三題、依單元直接練習、從民國 108～114 年命題趨勢題中隨機抽出 10 題，或從 AI 同觀念加強題本持續練習。英文聽力使用網站內的實體音檔，不需要付費 API、AI API 或 API Key；只有學生主動要求 AI 分析或建立相似題時，才會呼叫安全後端。

## 修改會考與模擬考日期

開啟 `config.js`，找到 `examConfig.examYears`。每個年度包含：

- `preparationStart`：準備期起點，用來計算已經過時間與整體準備進度。
- `finalExam`：正式會考名稱與日期。
- `mockExams`：四次模擬考名稱、日期與提醒文字。

日期一律使用民國年 `YYY-MM-DD`，例如民國 116 年 5 月 15 日請寫成 `116-05-15`。若要新增年度，複製一整個年度區塊並修改民國年份；也可以調整 `defaultYear`，控制初次設定時的預設年度。範例日期不是官方公告，正式使用前請換成學校或該年度正式日期。

## 本機開啟測試

最簡單的方法是直接雙擊 `index.html`。若瀏覽器對本機檔案有額外限制，建議在此資料夾啟動簡單的靜態網站伺服器：

```powershell
python -m http.server 8000
```

再開啟 `http://localhost:8000`。停止時在該視窗按 `Ctrl + C`。

建議依序測試：

1. 第一次開啟時填寫資料並送出。
2. 重新整理，確認直接回到個人首頁。
3. 新增一筆未來日期與一筆過去日期，確認排序及「已結束」標示。
4. 修改、刪除自訂日期。
5. 修改個人資料後重新整理。
6. 儲存今日小目標後重新整理。
7. 進入「五科學習」，完成國文、英文或數學今日任務。
8. 故意答錯一題，確認立即解析與錯題自動建立。
9. 進入「錯題整合」，從題庫錯題再次作答，並測試「標記已掌握」。
10. 重新整理，確認今日完成科目與錯題仍然存在。
11. 使用瀏覽器開發者工具切換手機尺寸（例如 375 × 812），確認底部導覽出現。
12. 按「重新設定」並確認回到初次設定頁。
13. 故意答錯一題，按「請 AI 教練帶我看這題」，確認會進入「錯題整合」且不會立刻公布答案。
14. 從「題庫錯題」完成五步驟，確認科目老師與筆記老師依序接手，並顯示九段診斷。
15. 在「錯題整合」選擇「已存錯題」，確認可完成開放式理解檢查與筆記整理。
16. 選擇「紙本拍照分析」，確認手機可啟動相機、電腦可選圖，並能收到題目辨識、九段分析與三題同觀念練習。
17. 完成一題 AI 分析，按「列印這份會考重點筆記」，確認列印預覽只包含該題解析、考點與筆記整理。
18. 確認畫面會分開詢問「是否收藏」與「是否建立相似題」，不會自動存入錯題本；再按「建立相似題練習」，回到對應科目確認 AI 題本可開始作答。
19. 下載備份檔，確認其中包含 `examMate.aiPracticeQuestions.v1`，換裝置後才不會遺失個人化題目。

## 上傳到 GitHub Pages

1. 在 GitHub 建立一個新的公開儲存庫，例如 `exam-journey`。
2. 將網站檔案放在儲存庫根目錄並推送到 `main` 分支。
3. 進入儲存庫的 **Settings → Pages**。
4. 在 **Build and deployment** 選擇 **Deploy from a branch**。
5. Branch 選擇 `main`，資料夾選擇 `/(root)`，按下 **Save**。
6. 等待 GitHub 完成部署後，Pages 頁面會顯示公開網址。

純前端網站不需要額外建置步驟。請注意：localStorage 只跟目前的瀏覽器與裝置綁定；學生換裝置或清除瀏覽資料後，資料不會自動同步。

## 下一階段擴充方向

目前先維持最小產品範圍。下一階段可以在不改變操作流程的前提下擴充：

- 增加五科正式題庫與完整單元分類。
- 依年級與程度調整每日任務難度。
- 讓錯題依科目與單元篩選。
- 加入簡單的讀書計畫，再由計畫產生每日任務。

在仍然只有單一裝置使用時，可以繼續採用 localStorage；需要跨裝置同步、多人使用或教師查看時，再規劃登入與雲端資料庫，並且不要把任何服務的 API Key 直接寫在前端。
