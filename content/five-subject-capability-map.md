# ExamMate 國中教育會考五科能力地圖 v1.0

## 文件定位

本能力地圖依據國中教育會考官方公布的各科考試內容、命題原則與等級表現整理，再轉化為 ExamMate 可用的「科目 → 領域 → 單元 → 能力」架構。

這不是教育部公告代碼的逐字重製，而是產品端的教學拆解。其目的有三個：

1. 讓學生知道自己正在練哪一項能力。
2. 讓每一道題目都能標記單元、能力與難度。
3. 讓未來的今日任務、錯題與學習紀錄使用同一套分類。

## 共通命題原則

- 以第四學習階段課綱的學習表現與學習內容為基礎。
- 題材以學生生活、學習經驗與公共議題為主。
- 不綁定單一教材版本，避免考冷僻、瑣碎知識。
- 除基礎知識外，更重視理解、統整、推論、轉譯與應用。
- 難度不是用篇幅決定，而是依解題所需的訊息量、推理層次與概念整合程度判定。

### ExamMate 共通能力層級

| 層級 | 學習表現 | 題庫難度建議 |
|---|---|---|
| 辨識 | 能辨認基本事實、符號、語意或概念 | 1 |
| 理解 | 能說明概念、提取明確訊息、完成單一步驟 | 2 |
| 應用 | 能將所學用於新情境，連結兩項訊息 | 3 |
| 分析 | 能比較、推論、判斷關係，整合多項訊息 | 4 |
| 評鑑與統整 | 能檢驗觀點、評估證據、跨文本或跨領域解題 | 5 |

# 一、國文

官方評量核心包括常用字形音義、詞語理解與使用、基本語文常識、文本統整與應用，以及句段篇章理解與賞析。ExamMate 將其拆為以下十個學生入口。

## 1. 字音

- 辨認常用字正確讀音。
- 辨別一字多音與語境讀音。
- 比較形近字、音近字讀音。
- 根據詞義判斷正確注音。
- 在句子中判斷讀音是否恰當。

## 2. 字形

- 辨認常用字正確字形。
- 區分形近字、同音字與音近字。
- 找出詞語或句子中的錯別字。
- 根據語境選擇正確用字。
- 修正文句中的字形錯誤。

## 3. 成語

- 理解常用成語的基本意義。
- 根據語境選用成語。
- 判斷成語使用是否恰當。
- 辨別近義、反義與易混淆成語。
- 理解成語的感情色彩與適用對象。
- 從上下文推測陌生成語的意思。

## 4. 國學常識

- 理解年齡、季節、時間與方位代稱。
- 正確使用稱謂、謙辭與敬辭。
- 認識常見文體與基本形式特徵。
- 理解古典詩歌、對聯、題辭的基本規則。
- 認識常見典籍分類與文化常識。
- 將文化常識應用於真實溝通情境。

## 5. 修辭

- 辨認譬喻、轉化、映襯、排比、層遞、設問、反問、誇飾、借代等常見修辭。
- 說明修辭在句中的表達效果。
- 比較不同表達方式造成的語氣差異。
- 根據溝通目的選擇適切修辭。
- 判斷修辭與文本情感、觀點的關聯。

## 6. 文意理解

- 理解句子表層語意。
- 根據上下文理解代詞、轉折與指涉。
- 推測關鍵詞語在文中的意思。
- 判斷句子間的因果、並列、轉折、條件關係。
- 概括段落重點。
- 推論未直接說明的態度、原因或結果。

## 7. 閱讀理解

- 擷取文本明確訊息。
- 統整分散於各段的資訊。
- 判斷主旨、觀點、寫作目的與對象。
- 分析人物動機、情緒與行為變化。
- 辨認文本結構與寫作手法。
- 比較多文本的共同點、差異與立場。
- 閱讀圖表、流程、公告、對話等非連續文本。
- 評估論點、證據與推論是否合理。
- 將文本訊息轉化為生活問題的解決方案。

## 8. 文言文

- 理解常用文言實詞與虛詞。
- 辨認古今詞義差異。
- 理解省略、倒裝等基本句法。
- 將文言語句轉化為合理白話語意。
- 掌握人物、事件、原因與結果。
- 推論人物性格、寫作寓意與作者態度。
- 比較文言文本與白話文本的觀點。

## 9. 白話文

- 理解記敘、說明、議論、應用等文本。
- 掌握人、事、時、地、物與事件發展。
- 判斷說明方法、論證方式與敘事觀點。
- 理解語氣、情感與價值判斷。
- 統整長文資訊並建立摘要。
- 評估文本資訊在生活中的可行性。

## 10. 綜合測驗

- 跨字詞、語法、修辭與閱讀整合判斷。
- 跨段落或跨文本統整訊息。
- 結合文字、圖表、表格與流程解題。
- 根據文本完成排序、分類、修訂或決策。
- 判斷資料可信度、觀點與證據。
- 將閱讀結果轉化為溝通或問題解決方案。

# 二、英文

官方考試內容涵蓋主題與體裁、溝通功能及語言成分，並以閱讀與聽力兩部分評量。題目重視自然語境，不以零碎文法記憶為主。

## 1. 文法

- 理解時態、助動詞、被動語態與完成式的基本使用。
- 理解名詞、代名詞、形容詞、副詞、介系詞與連接詞。
- 理解比較、條件、關係子句、不定詞與動名詞。
- 根據語境判斷句型與語法連結。

## 2. 短文閱讀

- 理解基本 1,200 字的核心語意與常見搭配。
- 根據上下文選擇適當字詞並推測字義。
- 問候、介紹、感謝、道歉與祝福。
- 請求、建議、邀請、同意與拒絕。
- 根據語氣、關係與情境選擇適當回應。
- 根據前後文選擇字詞或句型。
- 理解代名詞指涉與連接詞關係。
- 閱讀簡訊、電子郵件、公告、廣告、圖表與活動資訊。
- 交叉比對日期、時間、資格、費用與攜帶物等限制。

## 3. 長文閱讀

- 擷取人物、時間、地點、原因與結果等細節。
- 判斷主旨、標題與段落重點。
- 推論人物態度、立場與未明說訊息。
- 整合跨句、跨段資訊。
- 閱讀故事、信件、公告、廣告、新聞、圖表與網頁資訊。
- 比較多文本資訊並做決定。

## 4. 聽力

- 辨識單句與圖片或圖表的對應。
- 選擇日常問句的適當回應。
- 理解短對話與短文的明確細節。
- 判斷主旨、人物關係、地點與目的。
- 根據語氣與上下文進行簡單推論或猜字。

# 三、數學

官方考試內容分為六大主題，並重視從真實情境辨識數學問題、擬定策略、執行解題、說明理由及將結果轉回真實世界。

## 1. 數與量

- 正負數、數線、絕對值與大小關係。
- 質因數、倍數、因數與分數運算。
- 指數、科學記號、平方根與近似值。
- 比、比例、百分率、速率與單位換算。
- 等差數列與規律辨識。
- 估算、誤差與量感。

## 2. 空間與形狀

- 平面與立體圖形基本性質。
- 三角形、四邊形、多邊形角度關係。
- 全等、相似與比例線段。
- 圓、弧、弦、圓周角與切線。
- 周長、面積、表面積與體積。
- 幾何推理、作圖與圖形變換。

## 3. 坐標幾何

- 平面坐標與象限判讀。
- 點、線與圖形的位置關係。
- 由坐標求距離、面積或變化。
- 直線方程式與圖形判讀。
- 以坐標方法處理幾何問題。

## 4. 代數

- 代數式化簡與值的計算。
- 一元一次方程式與不等式。
- 二元一次聯立方程式。
- 乘法公式、因式分解與多項式。
- 一元二次方程式。
- 將生活情境轉化為代數關係。

## 5. 函數

- 變數、對應關係與函數概念。
- 線型函數與圖形。
- 二次函數與圖形特徵。
- 從表格、圖形與式子判讀變化。
- 以函數描述生活情境並預測結果。

## 6. 資料與不確定性

- 統計圖表的閱讀、比較與轉譯。
- 平均數、中位數、眾數與分布。
- 資料代表性、抽樣與可能偏誤。
- 簡單機率、樹狀圖與事件判斷。
- 根據資料做合理推論與決策。

## 7. 數學素養與表達

- 辨識情境中的已知、未知與限制。
- 選擇適切策略並執行多步驟解題。
- 使用式子、圖形、表格或文字表示想法。
- 檢查答案合理性與單位。
- 說明推理過程與結論。

# 四、自然

官方評量同時包含學習內容與學習表現。內容涵蓋自然界的組成與特性、現象規律及作用、永續發展；表現則包括科學認知、探究能力、科學態度與本質。

## 1. 生物與生命現象

- 細胞、生物體構造與層次。
- 養分、消化、循環、呼吸、排泄與恆定。
- 植物構造、運輸、光合作用與生殖。
- 遺傳、變異、演化與分類。
- 生態系、族群、能量流動與物質循環。

## 2. 物質與化學

- 物質狀態、密度、溶液與分離方法。
- 原子、分子、元素、化合物與週期性。
- 化學反應、質量守恆與反應速率。
- 酸鹼、氧化還原與生活化學。
- 有機物、材料與資源使用。

## 3. 物理現象

- 運動、速率、加速度與圖表。
- 力、壓力、浮力與平衡。
- 功、能量、能量轉換與守恆。
- 溫度、熱與熱傳播。
- 波、聲音、光與成像。
- 電流、電壓、電阻、磁與電磁應用。

## 4. 地球科學

- 地球內部、岩石、板塊與地質作用。
- 地震、火山與天然災害。
- 大氣、天氣、氣候與水循環。
- 海洋與臺灣自然環境。
- 地球運動、月相、潮汐與太陽系。

## 5. 永續發展

- 生物多樣性與環境變遷。
- 能源種類、轉換、效率與選擇。
- 天然資源、污染與循環利用。
- 氣候變遷、防災與風險判斷。
- 科技應用的效益、限制與影響。

## 6. 科學探究能力

- 從現象提出可檢驗問題。
- 提出假設並辨認變因。
- 規劃控制變因、公平測試與測量方式。
- 執行觀察、實驗與資料記錄。
- 閱讀表格、圖形與實驗結果。
- 分析資料、建立解釋並提出證據。
- 評估誤差、限制與改進方法。
- 分辨科學證據、推論與個人意見。

# 五、社會

官方內容涵蓋歷史、地理、公民與社會，並重視跨科整合、圖表資料解讀、公共議題、生活情境及全球關懷。

## 1. 歷史

- 歷史時間、紀年、史料與證據。
- 臺灣早期社會與多元族群。
- 清帝國、日本帝國與當代臺灣。
- 古代文明、傳統社會與文化交流。
- 近代國家、工業化、帝國主義與民主發展。
- 當代東亞、世界戰爭、冷戰與全球化。
- 分析事件原因、經過、結果與影響。
- 比較不同時代、地區與觀點。

## 2. 地理

- 地圖、比例尺、方向、坐標與地理資訊。
- 地形、氣候、水文、生態與自然災害。
- 人口、聚落、交通、產業與都市化。
- 臺灣區域差異與空間互動。
- 世界各區域的環境與人文特色。
- 資源、環境、全球化與永續議題。
- 解讀地圖、統計圖、照片與空間資料。
- 分析人地互動及區域差異原因。

## 3. 公民與社會

- 自我、家庭、學校、社群與文化認同。
- 社會規範、團體、文化差異與社會變遷。
- 權利、責任、人權、平等與法治。
- 民主、政府、選舉、公共意見與公民參與。
- 法律責任、權利救濟與生活法律。
- 生產、消費、市場、貨幣、勞動與政府經濟功能。
- 媒體識讀、資訊判讀與公共議題討論。
- 全球社會、國際組織與永續責任。

## 4. 社會領域共通能力

- 從文字、地圖、表格、統計圖與圖像擷取資訊。
- 將資料轉換成時間、空間或因果關係。
- 比較不同資料來源、立場與可信度。
- 運用歷史、地理、公民概念解釋生活議題。
- 分析政策或選擇對不同群體的影響。
- 提出有證據、兼顧多元觀點的判斷。

# 題庫標記建議

每道題至少標記：

- 科目
- 主單元
- 次單元
- 核心能力
- 難度 1～5
- 題型
- 素材類型：單句、短文、長文、對話、圖表、跨文本等
- 認知層次：辨識、理解、應用、分析、評鑑與統整
- 正確答案與解析
- 常見錯誤原因
