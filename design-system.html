DESIGN SYSTEM

同一套元件，陪學生學好五科。

五科只更換內容與辨識色，操作方式、文字層級、按鈕位置與回饋節奏保持一致，讓學生不用重新學習介面。

目前版本v1.0 UI Prototype

Color System

深藍建立信任感，靛藍負責主要操作，橘色用於時間提醒；成功與錯誤色只用於結果回饋。

Typography

優先使用系統內建的繁體中文字體，粗體用於方向與成果，內文保持寬鬆行距，讓國中生快速掃讀。

每次只專注一個清楚的小任務，完成後立即查看解析，再決定下一步。

Icon Style

使用單色、圓角外框與簡單符號；不使用寫實插圖或混雜風格。圖示永遠搭配文字，不單獨承擔意思。

Button

每個畫面只保留一個最重要的主按鈕。次要、安靜與危險操作使用不同層級，避免學生誤按。

Card

所有卡片使用白色底、清楚邊框、18px 圓角與輕量陰影。只有可點擊卡片才會在滑入時浮起。

Progress Bar

進度條必須同時顯示文字或數字，不只依靠顏色。動畫只在數值更新時短暫發生。

今日完成 2／3 科67%

Task Card

固定包含科目、時間、狀態、任務說明、進度與單一主要行動，讓學生一眼知道現在要做什麼。

Practice Card

題幹、選項與確認按鈕保持固定位置；學生選答案前，確認按鈕保持停用。

Wrong Question Card

錯題卡顯示題幹、錯誤次數與觀念提醒，提供「再答一次」與「已掌握」兩個行動。

Dialog

用於立即解析與需要再次確認的操作。內容保持短、焦點明確，關閉後回到原本流程。

Navigation

桌機使用頂部導覽，主要項目固定為首頁、五科學習與錯題。

Bottom Navigation

手機版固定於畫面下方，保留三個最常用入口；文字與符號同時顯示，單手也容易點選。
